# Grains

Welcome to Grains.

## Instructions

The chessboard has 64 squares. If you place 1 grain of wheat on the first
square, and then double the number of grains on each subsequent square, how
many grains are on each square, and what is the total?

- `square(1)` is 1 grain.
- `square(2)` is 2 grains.
- ...
- `square(64)` is \(2^{63}\) grains.

Work through the tests in `tests/grains.rs` by removing `#[ignore]` one-by-one.
