# Raindrops

Welcome to Raindrops.

## Instructions

Convert a number to a string, the contents of which depend on the number's factors:

- If the number has 3 as a factor, add `Pling` to the result.
- If the number has 5 as a factor, add `Plang` to the result.
- If the number has 7 as a factor, add `Plong` to the result.
- If the number has none of 3, 5, or 7 as factors, the result should be the number as a string.

Work through the tests in `tests/raindrops.rs` by removing `#[ignore]` one-by-one.
