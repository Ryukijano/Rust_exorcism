# Word Count

Welcome to Word Count.

## Instructions

Given a phrase, count the occurrences of each word.

Typical rules for this exercise:

- Words are compared case-insensitively.
- Punctuation does not count as part of a word.
- Apostrophes can appear *inside* a word (e.g. `don't`).

Work through the tests in `tests/word-count.rs` by removing `#[ignore]` one-by-one.
